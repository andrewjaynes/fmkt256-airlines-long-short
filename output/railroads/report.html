How to reuse this: new companies or new data, zero new code

The analysis is driven by a plain-text sector file. The code never changes. Only the list of tickers does.

1
Edit the ticker list
Open sectors/railroads.yaml in any text editor. Add, remove or replace tickers. For a new sector, copy the file (e.g. sectors/railroads.yaml) and change the name and tickers.
2
Run one command
python run.py sectors/railroads.yaml
Prices, financials, peer medians, ranks, charts and scores are all re-pulled and recomputed live for whatever tickers are listed.
3
AI writes the analysis
With a Claude API key, Claude searches the web and writes every one-pager plus the long/short memo automatically. Without one, the tool writes copy-paste prompts for Claude.ai or ChatGPT, still with no coding.

Methodology, sources and AI prompts

Quantitative data

All market and financial figures are pulled live from Yahoo Finance (via the open-source yfinance library) each time the report is generated. No numbers are typed in by hand. TTM margins are the sum of the last four reported quarters. Revenue growth compares the latest quarter with the same quarter a year earlier. Net debt = total debt (incl. leases) − cash and investments.

Composite score

Eleven metrics are converted to percentile ranks within the peer group (so the score is always relative), averaged into five pillars, then weighted per the sector file:

PillarMetrics (direction)Weight
ValuationEV/EBITDA ↓, forward P/E ↓25%
ProfitabilityOperating margin ↑, net margin ↑, ROE ↑20%
Balance sheetNet debt/EBITDA ↓, cash/revenue ↑25%
Momentum1-yr return ↑, distance from 52-wk high ↑15%
Street viewUpside to consensus target ↑, short interest ↓15%

Negative EBITDA or earnings make a multiple "not meaningful"; those companies receive the lowest score on that metric.

Division of labor: code vs. AI

Code does what must be exact: fetching, calculating, ranking, charting. AI does what needs judgment: researching recent earnings and news, writing the qualitative assessment, and making the final long/short call (it may override the screen if it explains why).
